# Analysers

A demo of [.NET analyzers](https://learn.microsoft.com/en-us/visualstudio/code-quality/roslyn-analyzers-overview?view=vs-2022).

# Quick start
```sh
dotnet build  # see the warnings generated by the analysers
dotnet test   # unit test the analysers
```

# Creating your own from scratch
The solution `MyAnalysers` in this directory was created with Rider. There
doesn't seem to be a `dotnet new` template for analysers, unfortunately. See
- https://github.com/dotnet/templating/issues/2113
- https://github.com/dotnet/roslyn-sdk/pull/612

Options I can see:
- create using Visual Studio
- create using Rider
- copy this solution/subprojects
